# 軽量な隠密脱出ゲーム（トップダウン2D）

## 基本コンセプト
- 真上から見たトップダウン2D視点
- 暗闇と制限された視界による緊迫感
- 視覚と聴覚の非対称な敵をかいくぐる純粋な隠密ゲーム
- 攻撃手段・道具は一切なし。見つからずに進むことが唯一の戦略
- 発見されたら原則死亡（ごく稀な状況のみ熟練で逃げ切れる）

---

## ゲーム構造
- 全5階層のランダム生成ダンジョン
- 迷路状の通路と部屋で構成される
- 階層が進むにつれてマップが広くなり、敵の数も増える
- 各階層の出口（階段）を見つけて次の階層へ進む
- 最終層の脱出口に到達することがゴール
- 1回の挑戦は10〜20分程度を想定
- 死亡時は最初の階層からやり直し

---

## 視界システム
- プレイヤーは前方に懐中電灯型の視野コーン
- 視野範囲は固定（成長要素なし）
- 背後・横は暗闇 → 回り込まれるリスクが常にある
- 視野の向きはキャラクターの正面方向に連動

### 視野外の表現（フォグオブウォー方式）
- **未探索エリア**：完全な暗闇
- **現在の視野内**：はっきり見える（地形・敵すべてリアルタイム）
- **既訪エリア（現在視野外）**：地形のみうっすら表示（減光）
- 敵は現在の視野内でのみ表示される
  - 一度通った場所に後から敵が侵入してもプレイヤーには見えない
  - 「さっきは安全だった部屋」が時間経過で安全でなくなる緊張感

### ミニマップ
- ミニマップは表示しない
- フォグオブウォーが既訪エリアの記録を兼ねるため、別途のマップ表示は冗長
- 探索感・没入感を優先する

### 視野コーンの暫定値（MVP）
| 対象 | 距離 | 角度 |
|---|---|---|
| プレイヤー | 6タイル | 45° |
| 視覚型敵 | 12タイル | 75° |
| バランス型敵 | 7タイル | 60° |
| 聴覚型敵 | なし（視覚を持たない） | - |

- 敵視野 > プレイヤー視野が基本方針
- 視覚型は長距離から発見してくる最大の脅威
- バランス型はプレイヤーとほぼ同等の視野距離

## 移動と音システム
| 移動方法 | 速度 | 音の到達距離（聴覚型基準） |
|---|---|---|
| 走る | 速い | 10タイル |
| 歩く | 通常 | 4タイル |
| 忍び足 | 歩くより遅い | 0タイル（無音） |

- 上記は聴覚型の感知範囲を基準値とする
- バランス型は基準値の0.7倍（走7 / 歩3 / 忍0）
- 視覚型は音を完全に無視（値なし）

### 壁による遮音
- 音源とリスナーの間に存在する壁タイル1枚につき、到達距離を **-2タイル** する
- 例：走る音10タイル、壁1枚挟むと実効8タイル、壁2枚で6タイル
- タイル直線（Bresenham）上の壁枚数で判定
- 0以下になった場合は感知されない

### 音の範囲表示
- ゲームプレイ中は自分の音の到達範囲を一切表示しない
- 走る／歩く／忍び足それぞれのリング半径は、ポーズメニューの「操作説明」画面で図示する
- 初回起動時は操作説明を強制的に表示する
- プレイ中は感覚で音の到達範囲を把握する設計

## 敵キャラクター

### 共通仕様
- 視野を持つ敵（視覚型・バランス型）の視野コーンはプレイヤーに薄く可視化される
  - 未発見：白 alpha 0.15
  - 警戒：黄 alpha 0.25
  - 発見：赤 alpha 0.35
- 聴覚型は視野を持たない（視野コーンなし）
- 敵の状態は本体の縁取り（オーラ）の色で表現する（視野コーンと同色系で統一）
  - 未発見：通常色（暗いシルエット）
  - 警戒：黄色い縁取り
  - 発見：赤い縁取り
- 全敵タイプで統一された表現を使う
- プレイヤーの心臓の鼓動で敵の接近を警告（全敵共通）
  - 最も近い敵までの直線距離（壁を無視）に応じて鼓動の速さが段階的に変化
  - 敵の種類は区別されず、「存在のみ」を伝える
  - **音とビジュアル両方で表現する**（聴覚と視覚の両方で察知可能）
    - 音：鼓動音が実際に聞こえる
    - ビジュアル：画面端の脈動エフェクト（距離に応じて強弱）

| 段階 | 距離 | 鼓動の速さ | 視覚エフェクト |
|---|---|---|---|
| 0 | 12タイル超 | なし | なし |
| 1 | 8〜12タイル | ゆっくり | 画面端がうっすら赤 |
| 2 | 5〜8タイル | 中速 | 画面端が脈動 |
| 3 | 5タイル以内 | 速い | 画面端が強く脈動 |

### 視覚型
- 前方視野コーンを持つ
- 長距離でも視野内なら確実に発見する
- 音は完全に無視する
- 対策：視野コーンの外側を通って回避する

### 聴覚型
- 視野を持たず、音のみで感知する
- 音が感知範囲に入ると反応する（忍び足なら気づかない）
- 対策：忍び足を使い、移動経路を慎重に選ぶ

### バランス型（雑魚）
- 視野7タイル / 60°（視覚型12タイル / 75°より明確に劣る）
- 音感知：走7 / 歩3 / 忍0（聴覚型の0.7倍）
- どちらの対策もある程度有効だが完璧ではない
- 単体では弱いが複数いると厄介

### 敵同士の衝突
- MVPでは敵同士が重なれる（衝突制御なし）
- 部屋単位巡回で団子になる可能性はあるが、体験への影響は軽微なため許容
- 最終目標では、目的地選択時に他の敵がいる部屋を避けるロジックを導入

### 未発見状態の巡回パターン

MVPでは以下2種を混在させる：

**部屋単位ランダム巡回（約70%）**
- 次の目的地となる部屋をランダムに選び、A*で移動
- 到着後は少し待機してから次の目的地を選ぶ
- 動線が部屋単位になるためプレイヤーが読みやすい

**待機型（約30%、主に視覚型）**
- 特定の地点で立ち止まり、ゆっくり左右にスキャンするように向きを変える
- 動かない監視者として「入ってはいけない場所」を作る
- 視覚型を待機にすると部屋の奥で見張る役割になる

最終目標では、上記に加えて**固定ルート巡回**（敵ごとに決まった経路）を追加する。

### 階層ごとの敵構成
| 階層 | 敵構成 |
|---|---|
| 1層 | バランス型のみ（チュートリアル的） |
| 2〜3層 | バランス型＋特化型が混ざり始める |
| 4〜5層 | 特化型中心＋混在構成 |

## 警戒段階システム

敵は3段階の状態を持つ。

### ①未発見
- 通常の巡回行動
- 通常の視野・感知範囲
- 敵同士の情報共有はなし（MVP）

### ②警戒
- 怪しい気配を感じた状態
- 移動せず、気配を感じた方向を向いたまま凝視する
- 持続時間：10秒（しつこめ）
- 待機型の敵もスキャンを止めて疑わしい方向を凝視する
- 10秒経過で警戒が解け、巡回を再開
  - 巡回型：次の目的地をランダムに選んで移動再開
  - 待機型：元の待機地点に戻ってスキャン再開

**未発見 → 警戒の遷移：**
- 視野距離の80%以上の地点で視野コーンにプレイヤーが入った
- 感知範囲の80%以上の地点で音が発生した

### ③発見
- プレイヤーを直接追跡する
- 追跡速度：通常の1.5倍（普通に走っても追いつかれる）
- 追跡中の視野・感知範囲：通常の1.2倍に拡大
- 視覚型：プレイヤーを最後に見た地点までA*で移動
- 聴覚型：音源の地点までA*で移動
- 到着後は探索フェーズへ移行

**未発見 / 警戒 → 発見の遷移：**
- 視野距離の80%未満の地点で視野コーンにプレイヤーが入った（直行）
- 感知範囲の80%未満の地点で音が発生した（直行）
- 警戒状態中にもう一度気配を感じた場合（再検知で発見へ昇格）

### 探索フェーズ（発見状態の延長）
- 追跡先到着後、その地点から半径5タイル以内をランダムに数点移動
- 持続時間：8秒
- 感知範囲は発見状態と同じ（1.2倍のまま）
- 探索中にプレイヤーを再発見すれば追跡を継続
- 8秒経過で警戒状態（10秒）に降格 → さらに10秒後に未発見へ復帰

### 逃走メカニクス
- 敵より速く走って逃げ切ることはできない
- 視線を切る・音を切ることで敵に「見失わせる」必要がある
- 具体的な手段：
  - 壁・角を挟んで視線を切る
  - 忍び足に切り替えて音を消す
  - 部屋に逃げ込んで遮音を活かす
- 感知範囲から外れ続ければ、上記の探索 → 警戒 → 未発見の流れで敵が落ち着く

## 操作方法

### 基本方針
- 移動方向と向きを独立させる（背後を見ながら前進できる）
- 左手＝移動、右手＝視点＋移動モードで役割を分離

### 操作一覧（MVP）
| 操作 | 入力 |
|---|---|
| 移動 | WASD |
| 向き | マウスカーソル方向 |
| 走る | 左クリック（押している間） |
| 歩く | 何もしない（デフォルト） |
| 忍び足 | 右クリック（押している間） |
| ポーズ | Esc |
| 階段・脱出口 | 接触で自動遷移 |

### 中クリック
- MVPでは未割り当て
- 将来的な特殊操作用の枠として予約

## 発見 = ほぼ死亡というゲーム性
- 攻撃手段がないため、発見されたら基本的に詰む
- 発見されないように立ち回ること自体がゲームの中心
- 警戒段階で気づいて立ち回りを修正できるかが生死を分ける

### 死亡判定
- 発見状態の敵がプレイヤーと **同一タイルまたは隣接1タイル** に到達した瞬間に即死
- 視線が通っただけでは死なない（発見→追跡→接触のプロセスを経る）
- 発見から接触までの間に視線・音を切れば逃走メカニクスで脱出可能
- 聴覚型・バランス型・視覚型すべて共通
