# MVP スコープ

本ドキュメントはMVP（Minimum Viable Product）の実装スコープをまとめたもの。  
詳細仕様は [WhatYouWant.md](WhatYouWant.md) および [map.md](map.md) を参照。

---

## MVPのゴール
コアゲーム性（暗闇・視野・音による隠密脱出）を動く形で検証すること。  
見た目や細かな演出はこの段階では最小限に留める。

---

## 技術スタック

### エンジン：Godot 4
- 完全無料・ロイヤリティなし（商用化に有利）
- HTML5エクスポートがネイティブで安定
- 同一プロジェクトからWindows/Mac/Linuxへエクスポート可能（Steam展開を見据える）
- 2D機能が成熟しており、タイルベースとの相性が良い
- エディタが軽量

### 言語：GDScript
- HTML5バンドルが軽量（10〜15MB程度）
- メモリ使用量が小さく、ブラウザ起動が速い
- Godotとの統合がシームレス
- C#版は.NETランタイムの分でバンドルが約30MB以上、メモリも大きくなるため不採用
- このゲームは計算負荷が高くなく、C#の実行速度メリットを活かせる場面がない

### 配布
- 第一段階：ブラウザ（HTML5エクスポート）でプレイ可能にする
- 第二段階：Windows/Mac/Linuxビルドを作成し、最終的にSteamで商用化

## ゲーム本体（MVP実装範囲）

### 基本
- トップダウン2D視点
- 全5階層のランダム生成ダンジョン
- 各階層の出口（階段）で次層へ進み、5層の脱出口でクリア
- 死亡時は1層から再開
- 攻撃手段・道具なし（純粋な隠密脱出）
- 死亡判定：発見状態の敵がプレイヤーと同一タイルまたは隣接1タイルに到達で即死

### 視界
- プレイヤー：距離6タイル / 角度45° の前方視野コーン（固定）
- 視野は成長しない
- 暗闇表現（視野外は見えない）

### 移動と音
- 走る / 歩く / 忍び足の3モード
- 音の到達距離（聴覚型基準）：走10タイル / 歩4タイル / 忍0タイル
- 忍び足は歩くより低速
- 壁遮音：直線上の壁タイル1枚につき到達距離-2タイル（0以下で感知されない）

### 敵キャラクター
- 3タイプ実装：視覚型 / 聴覚型 / バランス型
  - 視覚型：12タイル / 75°、音を完全に無視
  - 聴覚型：視野なし、音感知 走10 / 歩4 / 忍0
  - バランス型：7タイル / 60°、音感知は聴覚型の0.7倍（走7 / 歩3 / 忍0）
- 視野コーンはプレイヤーに薄く可視化（視野を持つ敵のみ）
- 敵の状態は本体の縁取り（オーラ）の色で表現
  - 未発見：通常色（暗いシルエット）
  - 警戒：黄色い縁取り
  - 発見：赤い縁取り
- 敵同士は重なれる（衝突制御なし）

### 敵AI
- 巡回パターン：部屋単位ランダム巡回（約70%）＋ 待機型（約30%、主に視覚型）
  - 部屋単位巡回：次の目的地部屋をランダムに選び、A*で移動
  - 待機型：特定地点で立ち止まり、ゆっくり左右にスキャン
- 3段階の警戒状態：未発見 / 警戒 / 発見
- 警戒への遷移：視野距離・感知範囲の80%以上で検知
- 発見への遷移：視野距離・感知範囲の80%未満で検知、または警戒中の再検知
- 警戒：10秒間その場で凝視、その後巡回再開
- 発見：通常の1.5倍速度で追跡、視野・感知範囲は1.2倍に拡大
- 探索フェーズ：追跡先到着後、半径5タイルを8秒探索 → 警戒10秒 → 未発見

### 操作方法
| 操作 | 入力 |
|---|---|
| 移動 | WASD |
| 向き | マウスカーソル方向 |
| 走る | 左クリック（押している間） |
| 忍び足 | 右クリック（押している間） |
| ポーズ | Esc |
| 階段・脱出口 | 接触で自動遷移 |

- 移動と向きは独立
- 無押しはデフォルトで「歩く」
- 中クリックはMVPでは未割り当て（特殊操作用の予約枠）

### 言語
- MVPは日本語で統一

### メニュー構成
**タイトル画面**
- ゲーム開始
- 操作説明
- 終了

**ポーズ画面（Esc）**
- 再開
- 操作説明
- タイトルへ戻る

**操作説明画面**
- 操作一覧（WASD移動、マウス向き、左/右クリック、Esc）
- 移動モードと音の到達範囲をリングで図示
- 敵タイプの説明は含めない（初見プレイヤーは自分で観察して学ぶ）

**ゲームオーバー画面**
- 「死亡」テキスト
- 何階で死んだかの表示
- 再挑戦（1層から） / タイトルへ戻る

**クリア画面**
- 「脱出成功」テキスト
- もう一度プレイ / タイトルへ戻る

### 画面UI要素（最小構成）
| 要素 | 表示位置 | 内容 |
|---|---|---|
| 現在の階層 | 左上 | 「Floor 2 / 5」 |
| 鼓動エフェクト | 画面端全周 | 距離に応じた脈動 |
| マウスカーソル | カーソル位置 | 小さな十字（OS標準カーソルは非表示） |

- 移動モードはあえて表示しない（指の感覚で把握する設計）
- HP・スタミナ・アイテム欄なども不要
- 敵視野コーンの色：未発見=白 α0.15 / 警戒=黄 α0.25 / 発見=赤 α0.35

### 鼓動警告
- 最も近い敵までの距離に応じて鼓動が段階的に速くなる
- 音とビジュアル両方で表現する（鼓動音＋画面端の脈動エフェクト）
- 敵タイプの区別はせず「存在のみ」を伝える

## マップ生成（MVP実装範囲）

### 生成方式
- 部屋＋通路方式（Rogue系）
- タイルベース（グリッド管理）
- 部屋は矩形のみ（L字・T字などの不整形は使わない）
- 接続：最小全域木 + 追加通路（部屋数の約20%）で中程度のループを作る
- 通路幅：**1タイル固定**
- 敵同士は重なれる（すれ違い問題を簡易回避）

### スタート・ゴール
- A*経路探索で実際の移動距離を計算し、マップ幅の一定割合以上を保証
- スタート部屋とその周辺には敵を配置しない
- 最終層のゴールは脱出口

### 階層ごとの数値

| 階層 | マップサイズ | 部屋数 | 敵数 | 部屋サイズ範囲 | 敵構成 |
|---|---|---|---|---|---|
| 1層 | 40×30 | 5〜6 | 2〜3 | 4×4〜8×8 | バランス型のみ |
| 2層 | 50×40 | 7〜9 | 3〜5 | 4×4〜10×10 | バランス型＋特化型混在開始 |
| 3層 | 60×45 | 9〜11 | 5〜7 | 5×5〜12×12 | バランス型＋特化型 |
| 4層 | 70×55 | 11〜13 | 7〜9 | 5×5〜14×14 | 特化型中心 |
| 5層 | 80×60 | 13〜16 | 9〜12 | 6×6〜15×15 | 特化型中心 |

## MVPで実装しないもの（最終目標で対応）

- 階層ごとのテーマ性（マップの性格づけ）
- 通路幅の1タイル/2タイル混在
- 敵同士の衝突制御（重ならないようにする）
- 部屋の不整形（L字・T字など）
- 見た目の作り込み・アセット
- その他演出（BGM、SE、エフェクト等の凝った実装）
- 視野コーンの可視判定をシャドウキャストに置き換え
- 固定ルート巡回の敵AI

### UI追加候補（最終目標）
- **死亡カウント／挑戦回数表示**：何回死んだか、何回目の挑戦か
- **画面ビネット効果**：常時うっすら四隅を暗くして暗闇感を強める常時エフェクト
- **死亡時のリプレイ**：死ぬ直前数秒を再生して何が起きたか振り返らせる

## MVPの検証目標

MVPができた段階で以下が確認できることを目指す：

1. 暗闇＋視野コーンの操作感が成立するか
2. 走る/歩く/忍び足の使い分けに戦略性が生まれるか
3. 3タイプの敵の非対称性がゲームとして機能するか
4. 警戒段階システムで逃走の駆け引きが成立するか
5. ランダム生成マップで毎回違う体験が得られるか
6. 5階層を10〜20分で踏破するテンポが適切か
